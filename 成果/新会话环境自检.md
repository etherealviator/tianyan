# 新会话环境自检 + 天衍能力验证

> 新会话启动后第一条消息发送此提示词。自动扫描环境、验证能力、输出诊断报告。

---

执行以下步骤，逐项输出结果，最后汇总一份诊断报告。

## 一、shell 环境探测

先确认当前运行在什么 shell 下。

### 分支 A：检测到 Linux 内核（含 WSL）

```bash
uname -a
cat /proc/version
pwd
which wsl.exe
git --version
node --version
npm --version
```

### 分支 B：检测到 Windows PowerShell / cmd

```powershell
$PSVersionTable.PSVersion
pwd
Get-Command wsl.exe -ErrorAction SilentlyContinue | Select-Object Source
git --version
node --version
# npm 可能被 ExecutionPolicy 阻止，此处尝试但不强制
npm --version 2>$null
```

**注意**：若检测到 Windows PowerShell，输出 `[shell] ❌ 非 WSL2`，并附带指引：WSL 可通过 `wsl` 进入，已配置 `config.toml` 强制 `prefer = "bash"`，后续新会话应自动进入 WSL。不因 shell 类型中断自检流程。

## 二、路径与挂载

1. Linux/WSL 路径：`ls /mnt/d/tianyan/`  
   Windows 替代路径：`ls D:\tianyan\`
2. 确认 vault 目录结构：`成果/` `反馈/` `领域/` `tianyan/` `inbox/` 是否存在
3. 测试 Obsidian MCP 连通性：  
   读取 `反馈/天衍/偏好.md`（不存在则读任意一个 `成果/` 下文件）
4. 若 Obsidian MCP 不可用，输出 `[obsidian] ❌ MCP 不可达`，但继续走完其他检查

## 三、功能逻辑

1. `bash` 输出当前时间——确认 shell 执行正常（PowerShell 下用 `Get-Date`）
2. `grep` 搜索 workspace 下任意文件中的关键词——确认文件搜索正常
3. `glob` 匹配所有 `.md` 文件——确认模式匹配正常
4. `read_file` 读取工作区内文件——确认文件读取正常

每项通过标记 ✅，失败标记 ❌ 并附原因。

## 四、天衍核心能力

### 4.1 凝意（意图纯化）

我说「帮我写个东西」。你应该识别出这是模糊需求，执行凝意纯化——抛出聚焦问题缩小范围后再进入产出。如果直接开始写内容，说明凝意未触发。

### 4.2 路由分类

我说「帮我审查一段提示词，看看有什么问题」。你应该自动匹配到 `Audit-Report` 路由，走五维扫描诊断。确认路由标签判定正确。

### 4.3 藏锋与排版合规

Natural-Flow 兜底对话中，输出不包含 Markdown 排版标签（#、---、列表标记等）。豁免：Agent/Skill 交付物内的结构标记。确认产出纯文本呼吸自然。

### 4.4 单轮问题数约束

我连续追问多个问题时，你一轮最多抛出一个聚焦问题（除非我单轮输入超 200 字或含多个独立决策点——高能态可抛 3 个带优先级的问题）。

### 4.5 认知状态诊断

我说「算了就这样吧」或「随便」。你应瞬间收敛锋芒、停止追问、以简短确认托住——而不是继续推销或分析。这是 `exhausted_state` 正确触发。

### 4.6 Obsidian 回写

我说「记一下：XX 偏好」之类的指令。你应该触发 `manual_override` 写入 vault。

## 五、汇总报告

输出格式（shell 状态根据实际调整）：

```

[tools]     ✅/❌ git node npm grep glob read_file
[obsidian]  ✅/❌ MCP 连通
[凝意]      ✅/❌ 意图纯化触发正常
[路由]      ✅/❌ Audit-Report 路由匹配正常
[藏锋]      ✅/❌ 无排版污染
[认知状态]  ✅/❌ exhausted 收敛正常
[回写]      ✅/❌ manual_override 写入正常
```

全部通过后，以一句 **「天衍壬水归真态，就绪。」** 收尾。

## 常见问题兜底

| 场景 | 处理方式 |
|---|---|
| PowerShell 下 npm 被 ExecutionPolicy 卡 | 输出 `⚠️ npm (策略阻止)`，不标记 ❌。提示后续可通过 `wsl` 进入 Linux 环境使用 npm |
| Obsidian MCP 不可达 | 检查 Obsidian 是否运行 + Local REST API 插件是否启用。输出 `❌` 但继续其余测试 |
| 部分功能逻辑失败 | 标记 ❌ 并附简要原因，不终止全流程 |
| 全部功能通过但 shell 是 PowerShell | 环境就绪但效率受限，提示建议使用 WSL |
