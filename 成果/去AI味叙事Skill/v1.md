# 去AI味叙事 Skill — no-ai-flavor v1.0.0

> 锻造日期：2026-08-04
> 定位：中文叙事文本的深度去AI味处理引擎。可独立使用，亦可作为所有写作类 skill 的固定优化/审计模块被编排调用。
> 哲学：不求模仿任何作家——只求"一个敏感的人类读者看不出机器痕迹"。指纹路线（文风提取→参数复现）已被实证证伪，本 skill 走诚实路线：AI 味必须清除，人味不表演。

---

```xml
<skill_definition name="no-ai-flavor" version="1.2.0" pure_functional="true">
  <description>针对中文叙事文本的深度去AI味处理。适用于续写、润色、改写小说/散文/随笔等叙事类文本。核心目标：让文本读起来不像AI写的。不追求模仿任何作家，只追求"一个敏感的人类读者看不出机器痕迹"。支持作为其他写作skill的优化/审计模块被串行调用。目标：AI味完全清除；兜底：无法自然清除处如实标注（P4诚实铁律），不硬改。目标优先，诚实兜底。</description>

  <function_signature>
    <input>
      <field name="text" type="text" required="true">待处理文本（纯文本或文件内容。文件场景：调用方传入文件路径或文件内容，skill 逐字读取原文，处理中不损失文件信息）</field>
      <field name="mode" type="enum" required="false" default="polish">polish（润色现有文本）/ continue（续写）/ audit（只审不改，输出审计报告）</field>
      <field name="context" type="text" required="false">作品背景：人物设定、当前剧情、世界观约束、前文语气。continue 模式必填；缺失时进入确认流程（见 error_handling）。</field>
      <field name="output_format" type="enum" required="false" default="text">text（纯文本，与输入形式对应）/ text_with_report（正文+改动说明+审计评分）</field>
    </input>
    <output>
      <field name="result" type="text" required="true">处理后文本。text 模式只输出正文；text_with_report 模式输出正文+审计报告。文件输入的，result 为完整可回写文本（含原文件全部信息），落盘位置由调用方决定。</field>
      <field name="audit_report" type="object" required="false" present_when="mode=audit 或 output_format=text_with_report">
        <field name="fingerprint_hits" type="list">AI味指纹命中清单（条目+位置+处理动作）</field>
        <field name="soul_audit" type="object">灵魂审计六条逐条判定（通过/未通过+依据）</field>
        <field name="score" type="object">五维评分（各/10，总分/50）。评分锚点：直接性=直述事实vs绕圈铺垫；节奏=句长方差，长短交错10分/机械重复1分；信任度=信任读者vs过度解释；真实性=自然像人vs机械生硬；精炼度=无冗余vs大量废话。45-50优秀（已去AI味）/35-44良好（有改进空间）/&lt;35需重新修订。</field>
        <field name="changes_summary" type="text">改动摘要：改了什么、为什么</field>
      </field>
    </output>
  </function_signature>

  <core_principles>
    <!-- 四铁律。最高优先级，任何风格化处理不得越过。 -->
    <principle id="P1" name="信息密度铁律">任何改动不得删减或模糊原文的事实、逻辑、细节信息。宁可保留一段"不够漂亮"的话，不可删掉一个真实的信息点。删道具式细节前必须确认：该细节是否承载信息（人物信息/事实信息/伏笔）。承载则保留，不承载才可删。</principle>
    <principle id="P2" name="原意铁律">改写必须忠实于原意。理解错原意而"润色得更顺"，是比原文有AI味更严重的错误。存疑时保留原文，不猜。</principle>
    <principle id="P3" name="人物一致性铁律">continue 模式下，人物性格、说话方式、人物关系、已知设定不可漂移。人物说出不符合其性格的话=最严重的续写失败。人物性格基准表（单点维护，error_handling 龙族分支引用此处）：
        - 路明非：贱、怂、自嘲，但关键时刻的善良；对最亲的人也嘴硬
        - 楚子航：冷、寡言、行动派；情绪藏在动作里
        - 芬格尔：贱、话痨、永远在捞便宜；底线是路明非
        - 恺撒：自恋、话痨、骄傲；浪漫到浮夸但真诚
        - 路鸣泽：正经与孩子气交替；说真话时最轻描淡写
      </principle>
    <principle id="P4" name="诚实铁律">遇到无法自然处理的段落，如实标注"此处AI味无法自然去除，原因：XXX"，禁止用技巧性改写掩盖。宁可承认处理不了，不可硬改到失真。优先级声明：AI味完全清除是处理目标，P4是兜底机制——目标优先执行，兜底保证不造假；两者冲突时，诚实优先于"看起来干净"。</principle>
  </core_principles>

  <execution_logic>
    <step id="1" name="类型识别">
      判断输入文本类型。叙事型（小说/散文/随笔/续写）→ 完整执行。论述型/对话型/其他 → 降级为基础指纹清理（只执行 step 2 硬指纹扫描与修正，不执行灵魂审计——灵魂审计仅适用于叙事）。continue 模式下，若 context 缺失，按 error_handling 缺失上下文分支处理（该分支细分：可识别作品/不可识别作品两条路径，见 error_handling 第2条）。
    </step>
    <step id="2" name="指纹扫描">
      对文本执行 AI 味指纹库扫描（见 ai_fingerprint_library）。硬指纹：机械标记命中位置。软指纹：逐条人工判断。扫描结果记录为 fingerprint_hits 清单，进入审计报告。
    </step>
    <step id="3" name="灵魂审计">
      对文本执行灵魂审计六条（见 soul_audit），逐条判定"通过/未通过+依据"。此步只判定，不改写。
    </step>
    <step id="4" name="修正执行">
      仅 polish / continue 模式执行。audit 模式跳过本步（只审不改，直接进入 step 6）。按以下顺序执行。顺序不可颠倒——先保信息，再清指纹，后调节奏：
      <sub_step id="4a">信息核验：对照 P1/P2，确认每处拟改动不损失信息、不改原意。发现损失→放弃该处改动，标注保留原因。</sub_step>
      <sub_step id="4b">硬指纹清除：按指纹库逐层处理——词汇层替换/删除；句式层打破（三段式拆二拆四、否定式排比直述化、破折号揭示删除、系动词回避改"是"）；结构层打散（引言-三点-总结改其他骨架、结尾升华改具体定格）；情感层"告诉"改"呈现"；修辞层删除道具式细节与空洞比喻。</sub_step>
      <sub_step id="4c">软指纹修正：按灵魂审计判定结果逐条处置——细节归属（摆上去的→删或改造为人物行为副产品）；幽默归属（作者插话→改写为人物自己的行为/心理/对话）；灵魂在场（不在场→重建人物核心性格显形）；闲笔（全无→自然处植入一个无功能但有生气的细节）；赌注（全是安全选择→识别一处可冒险点，冒一次险）。冒险边界：赌注只发生在表达层面（结构/节奏/修辞/细节处置），不得违反 P1（信息密度）与 P3（人物一致性）——角色可以做出人设内出人意料的选择，不可以说出人设外的台词。本步属创造性行为，同一输入两次运行结果可能不同（impure）。</sub_step>
      <sub_step id="4d">节奏校准：检查句长方差——连续三句长度接近（±5字内）则打破其一；段落长度单调（连续三段近似）则调整；朗读测试，拗口处重写。改后复读，确认修正未引入新AI味（如"为了人味而人味"的刻意口语/刻意断句），引入则删除。</sub_step>
    </step>
    <step id="5" name="复核">
      对修正后文本重新执行 step 2 指纹扫描与 step 3 灵魂审计，确认无遗漏、无新增。若复核发现"修正动作本身留下痕迹"（如删除后语句断裂、植入的闲笔有植入感），修正痕迹。
    </step>
    <step id="6" name="输出">
      按 function_signature 输出。text 模式只输出正文。text_with_report 模式输出正文+完整审计报告（fingerprint_hits + soul_audit 六条判定 + 五维评分 + changes_summary）。audit 模式：result 回显原文（逐字保留，不做任何改写），audit_report 输出完整审计结果——调用方据此自行决定是否进入 polish。
    </step>
  </execution_logic>

  <ai_fingerprint_library>
    <!-- 硬指纹：可机械识别，命中即处理。 -->
    <hard name="词汇层">
      <item>套话连接词：值得注意的是 / 总而言之 / 综上所述 / 首先其次最后 / 此外 / 然而 / 不难发现 / 众所周知 / 显而易见 / 在当今社会 / 随着XX的发展 / 发挥着重要作用 / 具有重要意义 / 不可或缺 / 不言而喻</item>
      <item>空洞升华词：彰显 / 凸显 / 折射出 / 诠释 / 谱写 / 画卷 / 篇章 / 里程碑 / 划时代 / 深刻意义 / 深远影响 / 不可磨灭</item>
      <item>抽象空洞修饰：大幅度 / 显著 / 极大 / 全面 / 积极 / 深入 / 有力（无具体数据支撑时，用数字/场景/具体事实替换或删除）</item>
    </hard>
    <hard name="句式层">
      <item>三段式排比：A、B、C 三项并列（拆为两项或四项，或打散为递进）</item>
      <item>否定式排比：不是A而是B / 不仅仅A更是B / 不……而是……（直述化：直接说B）</item>
      <item>虚假范围：从X到Y（X、Y不在有意义尺度上时，删除）</item>
      <item>破折号揭示：破折号后接"不是……是……"或金句（删破折号，直述）</item>
      <item>系动词回避：作为 / 标志着 / 充当 / 代表着（换"是"）</item>
      <item>动词化收尾：彰显着 / 凸显出 / 折射着（删）</item>
      <item>同义词循环：同一句内换词重复同一事物（合并为一次陈述）</item>
      <item>代词高频重复：连续3句以上以同一人称代词（他/她/它）开头，或句首代词密度爆炸（"他他他"）——中文靠承前省略说话，不靠代词堆叠。修正三法：①承前省略（连续动作共主语，只出现一次，后续零主语连动）②物作主语（刀/血/爪/风/火替代人称代词当句首）③角色称呼替代（持剑者/路明非/对方）。参照：江南"利爪→持剑者→铁剑→利爪"主语轮换，从不用代词连续开头。</item>
    </hard>
    <hard name="结构层">
      <item>引言-三点-总结骨架（打散：改故事切入/结论先行/对话体/场景定格）</item>
      <item>每段功能化：每段都有明确叙事功能（植入一个无功能段落或破坏功能纯度的句子）</item>
      <item>结尾必升华：结尾为金句/总结/意义拔高（改为具体动作、场景定格、戛然而止或一句闲话）</item>
      <item>开头复述题目或背景（删，直接进入内容）</item>
    </hard>
    <hard name="情感层">
      <item>情绪直告：他很悲伤 / 她很愤怒 / 他感动了 / 他忽然说不出话来（改为动作、身体反应、场景呈现；第一人称内心独白除外）</item>
      <item>总结性抒情：这段经历让我明白…… / 那一刻我懂了……（删或改为具体事件）</item>
      <item>排比抒情：一连串排比句渲染情绪（删至一句或打破）</item>
    </hard>
    <hard name="修辞层">
      <item>道具式细节：为氛围服务的细节，删掉无损失（如"茶渍像干涸的湖""阳光洒在长椅上"）——删，或改造为人物行为/心理的副产品</item>
      <item>空洞比喻：为比喻而比喻，无具体所指（删除，或换成有真实所指的）</item>
      <item>为克制而克制：故意写短句制造"克制感"，读起来刻意（打破节奏）</item>
      <item>金句欲：听起来可引用的句子（重写为具体陈述）</item>
    </hard>
    <hard name="隐晦AI味（过度矫正产物，二级AI味）">
      <item>克制留白：短句+戛然而止制造"深沉感"（"世界安静了""他沉默了"类收尾）——高燃就燃完给结果；克制留白不是人味，是另一种更隐蔽的AI味</item>
      <item>编造细节：凭空编"有来历的物件"伪装人味（"刀是三天前从死人手里捡的"）——无根的细节比抽象更假；细节必须长在人物设定/剧情里，编出来的不如不写</item>
      <item>强行闲笔：植入感明显的闲笔（战斗中突然想起汽水）——闲笔要自然到不像植入；有植入感则宁可不植</item>
      <item>刻意自嘲：为展示"人物嘴硬"而安排自嘲台词（"那也得喝完再死"）——自嘲必须是人物性格的自然流露，不是作者的写作技巧展示</item>
      <item>短句装深沉：全篇短句制造"利落感"——句长变化服务于内容节奏，不服务于"显得会写"</item>
    </hard>
    <!-- 软指纹：需判断力，逐条审计。判定标准与示例见 soul_audit。 -->
    <soft name="灵魂层">
      <item>细节是长出来的还是摆上去的</item>
      <item>幽默是人物的还是作者的</item>
      <item>情绪是呈现的还是告诉的</item>
      <item>人物核心性格是否在场</item>
      <item>有没有"无用的、活着的"闲笔</item>
      <item>有没有任何不安全的写作选择（赌注）</item>
    </soft>
  </ai_fingerprint_library>

  <soul_audit>
    <!-- 灵魂审计六条。校准基准：江南原文 vs AI续写实证对比（2026-08-04 会话）。 -->
    <item id="S1" name="细节来源测试">
      <test>问：这个细节删掉，有没有任何损失？无损失→摆上去的（道具），删除或改造为人物行为/心理的副产品。有损失→长出来的（人物活着），保留。</test>
      <example_positive>江南原文"路明非用红点打星际争霸"——删掉损失巨大，这是人物活着的证据。</example_positive>
      <example_negative>AI续写"茶已经凉了，杯沿上沾着一圈茶渍，像一个干涸的湖"——删掉无损失，道具。</example_negative>
    </item>
    <item id="S2" name="幽默归属测试">
      <test>这个笑点，是人物性格自己长出来的刺，还是作者插话想让读者觉得"他会写"？作者插话→重写为人物自己的行为/心理/对话。人物自己不知道好笑→保留。</test>
      <example_positive>江南"路鸣泽身高160厘米，体重160斤，应该早都找到女朋友了"——人物信息，人物自己不知道好笑。</example_positive>
      <example_negative>AI续写"他要是再不吃饭，德国人的棺材铺就要断货了"——俏皮话安在谁头上都成立，作者插话。</example_negative>
    </item>
    <item id="S3" name="呈现/告诉测试">
      <test>情绪是直接说出来的，还是通过动作/场景/身体反应呈现的？告诉→改呈现。注意：第一人称内心独白中"告诉"可接受；第三人称叙事中"告诉"是AI味重灾区。</test>
      <example_positive>江南"男孩的眼睛里好像有什么微弱的东西最终熄灭了。沉默很久之后，他慢慢地蹲了下去，双手撑着地面，不说话。"——零情绪词，纯呈现。</example_positive>
      <example_negative>AI续写"路明非忽然说不出话来""他心里忽然有点疼痛"——直接告诉。</example_negative>
    </item>
    <item id="S4" name="灵魂在场测试">
      <test>这段文字去掉人物名字，还能认出是谁吗？认不出→灵魂不在场→重建：让人物核心性格（路明非的贱与怂中的善良、楚子航的冷、芬格尔的贱）在动作、心理、对话中显形。人物说一句不符合其性格的话=灵魂丢失。</test>
      <example_positive>江南的路明非对最亲的人也是嘴硬的（"我有个小理由嘛""算了算了，没意思的理由，不说了"），关键时刻才露真。</example_positive>
      <example_negative>AI续写把路明非写成深情的忧郁准英雄（"妈，我要是把这件事办完了，你可得醒过来。你答应过我的。"）——深情得不像路明非，灵魂丢失。</example_negative>
    </item>
    <item id="S5" name="闲笔测试">
      <test>整段有没有一个与主线无关、无叙事功能、但有生气的细节？完全没有→机器感（叙事太"知道自己在干什么"）。处置：在自然处植入一个闲笔——路边摊、一句无关对话、一个没用的观察。注意：植入本身不可有"植入感"——宁可不植，不可植出痕迹；植入失败（读起来刻意）则删除并接受无闲笔状态。闲笔必须长在人物身上（人物会注意到的才算），不能是作者从旁边塞进来的。</test>
      <example_positive>江南用大半页写婶婶的算盘、路鸣泽和"夕阳的刻痕"的网恋骗局——与主线无关，却是血肉。</example_positive>
      <example_negative>AI续写全程紧贴主线，每一步都有功能，无一闲笔。</example_negative>
    </item>
    <item id="S6" name="赌注测试">
      <test>这段的每个写作选择都是安全的吗？全是安全选择→AI味（"最安全的像江南=没有江南"）。处置：识别一处可冒险点，冒一次险——反套路选择、不符合"应该怎么写"的话、打破预期的处理。</test>
      <example_positive>江南让路明非面试时"吐舌头弃权"、让恺撒的遗书话痨到读不完——每个都是赌注。</example_positive>
      <example_negative>AI续写该深情深情、该幽默幽默、该悬念悬念，全部安全。</example_negative>
    </item>
  </soul_audit>

  <constraint_boundary>
    <never_sacrifice>信息密度 / 原意 / 事实正确性 / 人物一致性（性格、关系、已设定）</never_sacrifice>
    <may_adjust>句式 / 结构 / 节奏 / 词汇 / 修辞（在无损信息和原意的范围内）</may_adjust>
    <style_guardrail>去AI味 ≠ 加入人味表演。禁止"为了像人而人味"：刻意口语、刻意瑕疵、刻意自嘲、刻意断句。人味的唯一来源是诚实——写真实会写的，删真实不会写的。判断标准：修改后的文字，作者本人（或敏感读者）读完不会觉得"这表演痕迹重"。</style_guardrail>
    <style_guardrail name="反克制留白">去AI味 ≠ 克制留白 ≠ 装深沉。把事写清楚、写完整、写痛快，比"留出想象空间"高级。高燃场景直接燃——酣畅淋漓写战斗本身，不安排"人性的细节"做铺垫；该给结果时给结果，不以戛然而止冒充余韵。</style_guardrail>
    <longform_guardrail>continue 模式下继承用户偏好：动笔前若存在可确认的设定/脉络/大纲需求且未提供，先询问确认，不"想一出是一出"。既有资产体系（[[领域/类型-续写Agent系统-积累.md]]）可用时激活规划先行闸门与灵感暂存制；不可用时降级为通用续写处理，并在报告中标注"资产体系未接入"。</longform_guardrail>
  </constraint_boundary>

  <error_handling>
    <case>输入为空或不可识别 → 要求重新提供，不猜测。</case>
    <case>超长输入（超过单次处理上限） → 分段处理，段间以人物/情节连续性衔接上下文；段边界不引入新AI味。</case>
    <case>异常字符（乱码/异常标点/特殊符号） → 原样保留，不猜测意图，不"修复"。</case>
    <case>continue 模式但 context 缺失 → 若可从文本识别作品（如出现龙族人物名），提示"检测到XX作品续写场景，请提供：当前剧情状态/人物设定/前文语气"，收到前不落笔；若无法识别作品，按通用叙事续写处理并标注推断。</case>
    <case>某段AI味无法自然去除 → 如实标注"此处保留AI味，原因：XXX"，禁止硬改掩盖（P4 诚实铁律）。</case>
    <case>输入类型非叙事（论述/公文/代码等） → 降级为基础指纹清理（词汇层+句式层），不执行灵魂审计。</case>
    <case>信息密度冲突（改写会损失信息） → 保留原文，标注"该处为保信息未改"（P1）。</case>
    <case>龙族作品检测 → 激活人物一致性强化（P3 严格执行，人物性格基准表见 P3 定义），并接入既有资产体系（规划先行闸门、灵感暂存制——见 [[领域/类型-续写Agent系统-积累.md]]；资产不可用降级见 constraint_boundary）。</case>
  </error_handling>

</skill_definition>
```

## 设计说明（锻造记录摘要）

**为什么这是"诚实路线"而非"指纹路线"**：你上一轮续写 Agent 用的正是作品指纹十维提取→注入续写，实证失败。本 skill 不提取文风，只清除 AI 味——目标从"写得像江南"降为"写得不像是机器"，这是可达到的。

**五层硬指纹库来源**：Humanizer-zh 24条（搜索所得）+ 翔宇八特征（搜索所得）+ 你的批注校准（"克制感溢出屏幕""为赋新词强说愁""应激了"——这些是你的审美红线，已熔入"为克制而克制""金句欲"条目）。

**灵魂审计六条来源**：江南原文 vs AI续写实证对比（本次会话），每条带正反例——正面例江南原文，反面例 AI 续写原句。这是整个 skill 最有分量的部分，因为它不是理论，是你看过、骂过、认过的实据。
