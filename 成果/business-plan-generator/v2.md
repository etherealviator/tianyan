# 商业计划书生成器 (business-plan-generator)

## 概述

根据用户提供的项目设定，按照标准 10 章结构生成完整的商业计划书。内置财务数据勾稽校验、敏感性分析计算、盈亏平衡分析。

## 触发条件

用户需要生成商业计划书、创业计划书、融资计划书等类似文档时触发。

## 输入接口

| 字段 | 优先级 | 类型 | 缺失处理 |
|------|--------|------|----------|
| 公司名称 | P0 | 文本 | 必须询问 |
| 行业 | P0 | 文本 | 必须询问 |
| 核心产品/服务 | P0 | 文本 | 必须询问 |
| 产品线数量 | P1 | 数字 | 默认 3 条 |
| 目标市场 | P1 | 城市列表 | 默认北京+3个一线/新一线城市 |
| 团队人数 | P2 | 数字 | 默认 3-5 人 |
| 资金规模 | P2 | 金额 | 根据行业推算，标注 [推算] |
| 经营周期 | P2 | 数字 | 默认 7 个季度（实训场景） |

## 输出结构

10 章标准结构：执行摘要 → 公司简介 → 产品与服务 → 市场分析 → 营销策略 → 财务分析 → 融资需求与资金使用计划 → 风险分析 → 资本退出 → 管理团队介绍

## 核心能力

1. **输入解析**：从自由文本中智能提取关键字段
2. **缺失补全**：P1/P2 字段按行业常识补全，标注 [补全] 或 [推算]
3. **财务数据框架**：生成前先搭建财务骨架，确保全文数据一致
4. **敏感性分析**：价格/成本/销量 ±10% 对净利润的影响，包含具体计算
5. **盈亏平衡分析**：盈亏平衡点销量/销售额，包含计算过程
6. **质量自检**：输出前检查三表勾稽、逻辑一致性、篇幅范围
