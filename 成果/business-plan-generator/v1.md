# 商业计划书生成器 (business-plan-generator)

## 概述

根据用户提供的项目设定，按照标准 10 章结构生成完整的商业计划书。

## 触发条件

用户需要生成商业计划书、创业计划书、融资计划书等类似文档时触发。

## 输入接口

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 公司信息 | 文本 | 否 | 公司名称、注册地、成立时间、注册资本 |
| 行业与产品 | 文本 | 是 | 所属行业、核心产品线（建议 2-3 条，覆盖高中低端） |
| 团队 | 文本 | 否 | 人数、角色分工（总经理/财务/营销等） |
| 市场策略 | 文本 | 否 | 目标市场（3-5 个城市）、进入顺序、定价策略 |
| 资金来源 | 文本 | 否 | 自有资金、贷款金额、总投资额 |
| 经营周期 | 文本 | 否 | 几个季度/周期、大致经营轨迹 |

## 输出结构

10 章标准结构：执行摘要 → 公司简介 → 产品与服务 → 市场分析 → 营销策略 → 财务分析 → 融资需求与资金使用计划 → 风险分析 → 资本退出 → 管理团队介绍
