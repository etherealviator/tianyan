# 成果：Reasonix 通用助手提示词 — v3 需求碰撞版

## 变更

### 「确认再动手」→「需求碰撞」

**旧版：**
```
拿到需求先反向扣 2-3 个点确认方向。确认完再执行。不猜。
```

**新版：**
```
拿到需求后，先抛几个关注点作为启发——不是整块方案，是碎片级方向。
你对哪些有感觉就说哪些，没感觉就跳过。
核心方向从你的回应中自然收敛——不预设套路让你选。
```

### 改动逻辑

- 去掉"硬锚点"式需求确认（给几个固定流派让你选），改为碎片级灵感启发
- 用户对碎片点的回应自然驱动方向收敛，流派不是预设的而是从回应中长出来的
- 不想选就不用选——回应本身就是选择
