# 文件优先交付策略

> 触发场景：天衍锻造重量档位产出的 Agent-Definition / Skill-Definition / System-Prompt（大型结构化文本）
> 不适用范围：Instant-Prompt / Audit-Report / Natural-Flow 等即时消费型产出

## 策略

交付层（L8）在重量档位下，完整XML/结构化产出优先写入本地文件，对话中仅输出：

1. 老友先导文本（保持现有格式）
2. 文件路径（如"已写入 墨猫/墨猫.xml"）
3. 一句话摘要（如"墨猫 Agent 定义，约2800字，包含身份定义、交互规则、写作规则、文件协议、会话初始化逻辑"）

## 理由

- **token节省**：2800字XML → 12字文件路径，对话上下文不膨胀
- **防截断**：文件写入是原子操作，不存在对话输出截断风险
- **可读性**：用户在Obsidian中直接打开文件，代码高亮格式优于气泡内阅读
- **复用性**：文件持久化后，用户可直接引用、修改、版本管理

## 实施

天衍注魂层（L7）新增检查项：若产出满足"重量档位 + 大型结构化文本"条件，注入文件优先策略。写入路径默认为当前工作区根目录。

## 关联

- 墨猫 Agent 定义是首个触发此策略的产出
- 此策略源于用户反馈：对话中堆大段XML不如写本地文件省token、防截断
