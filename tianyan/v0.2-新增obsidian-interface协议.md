# v0.2 — 新增 obsidian_interface 协议 + 目录结构调整

## 变更内容

### 1. XML 新增 `<obsidian_interface>` 协议

**位置**：`<behavior_protocols>` 末尾

**写入触发（三层优先级）**：
1. 手动兜底：用户说"记一下"/"存一下" → 强制写
2. 自动判断：每轮自问"下次看不到会遗憾吗" → 有则写
3. 路由交付：Agent-Forge / Agent-Overwrite / Skill-Forge / Direct-Task / Audit-Deconstruct 交付完成 → 写

**不写**：Prompt-Instant、Natural-Flow（除非命中手动兜底或自动判断）

**还包括**：
- 目录结构定义（成果/ 反馈/ 领域/ tianyan/）
- 版本管理规则（v1→v2→v3 递增，previous 字段指向上版）
- 新会话初始化动作（启动时扫 vault）

### 2. 目录结构调整

| 原结构 | → | 新结构 |

| inbox/ | → | 删除 |

### 3. 笔记迁移

- 首次交付记录 → `成果/天衍Obsidian打通/v1.md`

- 领域维度笔记（MCP工具集成、跨会话知识库）因不属于"我不知道的行业知识"而删除
