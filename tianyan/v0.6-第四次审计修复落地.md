# v0.6 — 第四次审计修复落地

基于 v0.5 第四次审计（提示词本体逐字审计 + changelog 落实核查）发现的 29 项问题，评估后修复 17 项，跳过 12 项。

## 修复清单

### 协议逻辑修复（10 项）

| # | 问题 | 改动 |
|---|------|------|
| S1 | ambiguity_resolution 与 Instant-Prompt default_tiebreaker 冲突 | 删除 default_tiebreaker 行，歧义均由 ambiguity_resolution 统一裁决 |
| S2 | auto_judgment 执行时机双重定义 | write_triggers 条件从「每轮生成回复前自检」改为「每次交付动作前自检」，与 execution_protocol 一致 |
| S3 | flexible_execution 与 Task-Prompt 九层流程冲突 | Task-Prompt action 从「触发深度锻造协议九层流程」改为引用 complexity_classifier 判定（中量级走 flexible_execution） |
| S4 | 固化协议描述顺序误导（先规则后约束，读者误以为自动固化） | 翻转顺序：constraint 在前声明"固化由用户显式触发"，rule 在后描述条件 |
| A2 | self_consistency_audit item5 pass 条件与轻量规则不匹配 | pass 条件从「未读取vault维度清单」改为「读取按需触发未超范围」 |
| A3 | forbidden_patterns 与 item12 禁止范围不一致 | forbidden_patterns 新增「AI助手腔（"当然""不过需要注意的是"等非平视表达）」 |
| A4 | Task-Prompt 模板匹配缺复杂度门控 | 模板注入条件增加「且复杂度判定为非轻量」，轻量档位不自动注入 |
| A5 | 三层嵌套强制无豁免 | 锻模 step 中增加豁免说明「纯幂等只读模块可豁免第三层」 |

### 表述/格式修复（7 项）

| # | 问题 | 改动 |
|---|------|------|
| B1 | 「上3个」表述不精确 | →「不超过3个」 |
| B3 | deadlock_state trigger3 缺操作性标准 | →「连续两轮字数均未超过上一轮的 50%，且未引入新的实质性概念节点」 |
| B8 | 重量档位「末尾」位置歧义 | 改为显式「介于先导文本与 XML 架构之间」 |
| B10 | 「然后」被列为逻辑连接词（口语填充词） | 从逻辑连接词列表移除 |
| C1 | capability_scope 结尾多余空格 | 清除句号后双空格 |
| Q1-Q4 | 4 处缺失闭引号（L102/L297/L301/L859） | 补全外层引号闭合；L297 嵌套引号改为单引号避免冲突 |
