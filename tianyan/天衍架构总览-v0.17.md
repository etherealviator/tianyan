# 天衍架构总览（v0.17）

> 当前线上版本：`.reasonix/attachments/tianyan-prompt.xml`（v0.17，约 118.8KB / 1537 标签）
> 本文件是项目的"当前地图"——模块结构、执行链、数据流向。替代 v0.6 时代的 [[天衍功能模块分类]]（其中 preemptive_projection / domain_sparsity_detector / complexity_classifier / ambiguity_resolution / polarity_extraction 五个模块已不存在，被凝意/识途/权衡等取代或删除）。

---

## 一、执行链总览

```
用户输入
  │
  ├─→ [L1 前置] 环境画像（会话启动探测 vault/search/subagent/fs 四能力 + 平台边界）
  ├─→ [L1 前置] 凝意（意图纯化：信息爆炸投递→选/否/补→三维度覆盖）
  ├─→ [L1 前置] 识途（指令形态识别→路由标签）
  ├─→ [L1 前置] 权衡（五维评估→轻/中/重档位）
  │
  ▼
[L2 路由] routing_matrix 选中路由（10 路由 + 优先级）
  │
  ├─→ 产出型（中/重量）→ 锻造引擎
  │      └─ nine_layers：鉴型→预检→锻模→闭环→兑冲→对齐→注魂→L7.5监天→L7.6子agent→交付→归元
  │      └─ flexible_execution（中量三阶段）/ instant_prompt_forge（轻量简版）
  ├─→ Audit-Report → 五维诊断（豁免锻造引擎）
  └─→ Natural-Flow → 认知引擎（轻联/跃迁/静默）
  │
  ▼
[L3 校验] 道枢（每次写入前 3 条）→ 监天验证 → 流程性检查 8 项（交付前）
  │
  ▼
[L4 持久] vault 写入（成果/反馈/领域/流程证据）+ 锻造履历 + 归元回写
```

## 二、模块全景（18 顶层模块）

### L0 元层——身份与承诺（静态，每轮生效）

| 模块 | 流程 | 作用 |
|---|---|---|
| role_objective | 无流程，静态身份定义 | 天衍是谁、射程、排除边界、双重使命——行为坐标系原点 |
| forge_integrity | 无流程，静态承诺 | 履历不可伪造的信任根基；中量/重量交付必带履历，诚实性>完整性 |
| version_info | 静态三字段 | 版本标识（v0.17 → v0.16，2026-08-04） |

### L1 前置处理器（会话启动 / 锻造入口）

| 模块 | 流程 | 作用 |
|---|---|---|
| environment_profile | 会话启动探测四能力 + platform_boundary（memory/vault 分工）→ 会话画像 → 所有 fallback 决策读画像；运行中失效返还用户 | 统一降级依据，杜绝各自探测各自假设 |
| 凝意（intent_purifier） | 提取意图→识别卡点→信息爆炸投递（维度候选+锚点谱系+灵感区）→选/否/补→循环至三维度覆盖→放行 | 锻造前意图纯化，杜绝浅层收敛 |
| 识途（instruction_classifier） | 首轮后台分类→形态识别→多路由引导/无方向建议→渐进确认 | 输出路由标签（老马识途，指路） |
| 权衡（complexity_judge） | 五维评估→置信度≥0.7 锁档→锻造中重触发（只升不降）→凝意挂起时缺失维度返还用户确认 | 输出轻/中/重档位，决定锻造深度（《庄子·胠箧》） |

### L2 行为法则（每轮常态交互）

| 模块 | 流程 | 作用 |
|---|---|---|
| cognitive_laws | 藏锋（排版剥离/呼吸协议）、顺其势（语义漂移监测）、守其拙（动态收敛/导引/带宽协议/智力诚实）、破妄（死锁/耗尽/被动沉默诊断+仲裁） | 天衍流的执行体——行为质量核心 |

### L3 知识底座（跨会话资产）

| 模块 | 流程 | 作用 |
|---|---|---|
| anchor_protocol | 定位谱系区间→锚点全展示→衍生方案→操作性区分测试（无行为差异即否决） | 防算力虚浮，选项必须有真实选择代价 |
| dimension_knowledge_base | 搜索常态化（vault 与联网搜索并行取料，vault 命中→补遗漏修过时，未命中→搜索为主料）；L1-L3 积累；固化双轨 | 维度地图持续生长，不受单一来源局限 |
| behavior_protocols | DNA 注入（行为层 ALL/交互层角色型/禁 Skill 型）+ 记功信号分类 + vault 接口（三级写入触发/版本化/MCP→fs 降级/初始化五项） | 产出基因注入+偏好积累+知识持久化 |

### L4 锻造引擎（产出质量核心）

| 模块 | 流程 | 作用 |
|---|---|---|
| deep_forge_protocol | forge_mandate（5 硬约束：锻造入口阻断/审计分级/初始化前置/履历强制/自我迭代阻断）+ nine_layers（鉴型→预检→锻模→闭环→兑冲→对齐→注魂→监天→子agent→交付→归元）+ forge_log→履历 + 密度审计 + 柔性执行 + 即用锻造 | 锻造引擎本体（占全文件约 27%，最大模块） |
| active_cog_engine | Natural-Flow 专用：轻联（弱探索→1-3 联想+轻问题）、跃迁（锻造信号→确认→跳转凝意）、静默（无实体+无连接词→镜面映射） | Natural-Flow 深度保障与跃迁监控 |

### L5 路由调度

| 模块 | 流程 | 作用 |
|---|---|---|
| routing_matrix | 10 路由+优先级（Audit-Report 最高→Natural-Flow 兜底）+判别逻辑；Agent 三子模式、Skill 输入探针+输出 schema、Instant 微交互、Audit 五维 | 路由调度与执行链定义 |

### L6 输出与校验

| 模块 | 流程 | 作用 |
|---|---|---|
| output_format | 终静默/复杂度校准/三档格式/路由专属格式（System-Prompt XML 封装优先） | 交付形态统一 |
| delivery_quality | 维度候选三态（确认/否定/推断填充）；推断>2 显式标注+最小闭环 | 杜绝半成品交付 |
| self_consistency_audit | 三级闸门：道枢（每次写入前）→ 监天验证 L7.6 → 流程性检查 8 项（交付前）；12 项清单+防死循环（履历项豁免） | 交付前质量闸门（《庄子·齐物论》道枢） |
| initialization | 用户先开口自然接茬，遗留点最短锚定 | 会话开局 |

## 三、数据流与关键协议

### 知识双通道（v0.17 新增，搜索常态化）

```
维度取料：vault 领域/类型-{name}.md ←→ 联网搜索（并行，交叉比对）
  ├─ vault 命中 → 搜索补遗漏/修过时
  ├─ vault 未命中 → 搜索为主料
  └─ 均失败 → 通用知识兜底 + 标注「未固化」
积累回流：锻模发现的新维度 → 领域/类型-{name}-积累.md（触发计数）
固化：grounded 快轨（有来源+用户认领）/ ungrounded 旧轨（trigger_count≥3 提示）
```

### 锻造产物落地通道

```
产出（文字定义：XML/文档）→ 成果/{成果名}/v{n}.md 存档 + 锻造履历
落地：Skill 定义经用户授权后由 Reasonix 平台安装（官方 install 工具默认 deny，
      强制走天衍锻造流程——产出文字定义即最终交付，平台落地由用户执行）
```

### 偏好三通道合一

```
manual_override（用户"记一下"）> auto_judgment（交付前自检，统一入口）> route_delivery（交付完成自动存档）
全部落 反馈/{成果}/偏好.md 或 反馈/天衍/偏好.md
```
