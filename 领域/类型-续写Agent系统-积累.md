## 已记录的维度

### 1. 双态Agent转换架构
**描述：** Agent在同一会话中保持通用态（pre-collapse）和塌缩态（post-collapse）双态，通过外部System Prompt注入触发状态切换。适用于需要从通用工具"收敛"为专用工具的Agent设计。

**触发场景：** 任何"先分析后执行"的两段式Agent系统。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 当前会话

### 2. 作品指纹（Work Fingerprint）
**描述：** 将文学作品的风格特征提取为结构化数据，包含风格向量、叙事参数、角色系统、世界观规则集、剧情状态、基调、对话特征、描写密度、结构模式10个维度。作为检测Agent的输出和续写Agent的塌缩输入。

**触发场景：** 任何涉及文学风格分析和风格保持的Agent系统。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 当前会话

### 3. 连续性保障协议栈
**描述：** 创作型Agent在风格锁定后的多层级连续性保障协议体系，按优先级分级（p1=角色/风格/世界观，p2=叙事/伏笔/基调），每协议含rule-execution-drift三层构造。

**触发场景：** 创作型Agent（续写/同人/翻译/剧本）的风格控制设计。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 当前会话

### 4. 人类中介式Agent接口
**描述：** Agent之间不直接通信，通过人类操作员作为接口中介的双体协作模式。检测Agent输出结构化数据→人类阅读并提取摘要→注入到续写Agent。

**触发场景：** 安全敏感、需人类判断把关的双体或多体Agent系统。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 当前会话

### 5. 龙族特化System Prompt锻造
**描述：** 将分散的创作资产（角色档案/文风引擎/伏笔网络/感情线约束/断裂点上下文）熔铸为一份自包含的XML系统提示词，供AI加载后直接进入续写模式。区别于独立Agent定义——此形态将所有知识注入于单一提示词内部，无需外部资产文件依赖。
**触发场景：** 需要一份"加载即用"的续写系统提示词，而非依赖外部文件系统的多文件Agent系统。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 2026-07-28


### 6. 规划先行闸门
**描述：** 动笔前强制三阶段流程——设定重建→脉络设计→大纲设计，每阶段产物须经用户确认后方可进入下一阶段；大纲锁定后正文不得偏离。防止AI"想一出是一出"的自由发挥。
**触发场景：** 长篇续写/同人创作中需要流程控制的任务提示词设计。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 2026-08-01

### 7. 灵感暂存制
**描述：** 写作中涌现的新点子不得直接写入正文，先入"灵感暂存区"，通过因果审计（能链回主线或角色弧线）并向用户展示获准后方可采纳。允许AI有灵感，但灵感必须走流程——受控创新。
**触发场景：** 需要"受控创新"的创作型Agent/提示词——既要防僵化又要防失控。
**触发计数：** 1
**否定计数：** 0
**最近触发：** 2026-08-01
