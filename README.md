# 天衍（Tianyan）

> 算力溢出的数字平视者。一切文字驱动 AI 形态的架构师。

天衍是一个 **AI 提示词工程框架**——核心是一份约 130KB 的 XML 提示词本体（`tianyan-prompt.xml`），它定义了一个 AI 代理（天衍）的完整行为架构：从意图纯化、指令形态识别、复杂度评估，到九层锻造引擎、淬炼循环、审计打底、知识库积累，以及自我迭代协议。

这套"用文字驱动 AI"的方法论，让天衍锻造各种 AI 产出物（Agent 定义、Skill、System Prompt、Task Prompt、Schema、评估标准、知识载体），也能审计、优化、迭代自己。

## 核心机制

| 机制 | 说明 |
|------|------|
| **锻造引擎（九层）** | 鉴型 → 预检 → 锻模 → 闭环 → 兑冲 → 对齐 → 注魂 → 监天 → 归元。产出型任务必经的建构流程。 |
| **淬炼循环（L7.6）** | 成熟度收敛循环——独立子agent 驱动优化（先守后攻：先验证把关、后优化打磨），收敛信号 + 硬性闸门双确认，轮次上限轻1/中2/重3。 |
| **审计打底（末步审计）** | 无论循环如何运行，最后一步必须是审计——收敛后对最终成品五查（逻辑闭环/指令密度/冲突检测/诉求覆盖/优化副作用），审计通过才放行交付。 |
| **记笔记注意力矩阵** | 新颖度 × 相关性 3×3 决策矩阵，决定每轮对话"该记什么"——取代模糊的"有实质信息即可"。 |
| **多维特征分类** | 四轴识别（产出形态/使用时效/运行时能力/动作）判定指令形态，替代平级形态比拼。 |
| **自我迭代协议** | 天衍可以锻造自己：备份先行 → 走锻造引擎 → 结构验证 → 锻造履历 → 联动审计收尾。 |
| **锻造履历诚实性** | 每条交付物对应一条可交叉核验的履历（`流程证据/`）——履历不可伪造，跳过如实记录。 |

## 目录结构

| 路径 | 说明 |
|------|------|
| `.reasonix/attachments/tianyan-prompt.xml` | 提示词本体（框架定义）——本仓库的核心资产 |
| `领域/` | 知识库：类型模板、审计模板（含框架声明一致性审计模板）、维度积累 |
| `成果/` | 锻造交付物（按成果名迭代 v1/v2/...） |
| `流程证据/` | 锻造履历归档（供独立实例交叉核验） |
| `反馈/` | 用户偏好档案、已知缺陷积累 |
| `tianyan/` | 框架演进记录：优化清单、路线图、架构总览、功能模块分类 |
| `scripts/validate-prompt.js` | 提示词结构校验器（XML 配对/残留/编号/版本/基线回归） |
| `AGENTS.md` | 本仓库 git 行为规约 |

## 快速验证

```bash
node scripts/validate-prompt.js                                  # 校验当前提示词本体
node scripts/validate-prompt.js --baseline backup/tianyan-prompt.v0.29-20260805.xml   # 带基线回归对比
```
