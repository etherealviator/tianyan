# 审计维度模板 — Skill

> 监天审计维度体系的一部分。适用于 Skill-Definition 类型交付物的审计。
> 状态：已固化

## 通用维度（所有 Skill 适用）

| ID | 维度 | 检查内容 | 严重等级 | 判定方法 |
|----|------|---------|---------|---------|
| GS01 | 输入输出 schema | 输入是否有字段名/类型/是否必填/缺省行为？输出是否定义到 schema 级（字段名/类型/是否必返/嵌套结构/空值处理）？ | 阻断 | 检查 function_signature 中的输入输出定义 |
| GS02 | 核心逻辑可执行性 | 执行逻辑是否有明确的步骤序列？每一步是否有可验证的完成条件？ | 阻断 | 检查 execution_logic 步骤定义 |
| GS03 | 边界场景 | 空输入、全缺省、超长输入、异常字符——各场景下的行为是否有定义？ | 警告 | 枚举边界输入类型，检查对应处理分支 |
| GS04 | 版本与编排 | version 字段是否存在？若涉及多 Skill 协作，编排协议（串行/并行/条件分支/错误传播/回滚策略）是否定义？ | 警告 | 检查 version 字段和 orchestration 模块 |
| GS05 | 指令密度 | 是否存在"酌情处理""适当优化""灵活处理"等泛化表述？异常处理是否具体到行为而非原则声明？ | 警告 | 逐句扫描泛化模式 |
| GS06 | AI味检测 | 与 GA07 相同。 | 警告 | 同 GA07 |
| GS07 | 设计哲学一致性 | 严格/宽容轴的选择是否与输入校验逻辑一致？静默/可见轴的选择是否与过程输出一致？ | 警告 | 对比设计哲学声明与实际行为定义 |

## 纯功能型 Skill 专用（pure_functional: true）

| ID | 维度 | 检查内容 | 严重等级 | 判定方法 |
|----|------|---------|---------|---------|
| GP01 | 接口文档密度 | 输入输出字段是否有注释说明其语义？复杂类型是否有示例？ | 建议 | 检查 schema 注释和示例 |
| GP02 | 幂等性声明 | 多次相同输入是否产生相同输出？若否，是否声明了副作用？ | 警告 | 检查是否标注 pure/impure |
| GP03 | 依赖声明 | 是否依赖外部系统/数据源/运行时环境？依赖不可用时行为如何？ | 警告 | 检查 dependency 声明 |
