# 审计维度模板 — Task Prompt

> 监天审计维度体系的一部分。适用于 Task-Prompt 类型交付物的审计。
> 状态：已固化

| ID | 维度 | 检查内容 | 严重等级 | 判定方法 |
|----|------|---------|---------|---------|
| GTP01 | 前置条件覆盖 | 执行任务所需的前置条件（输入数据/上下文/用户准备）是否全部声明？遗漏的执行中可能卡住。 | 阻断 | 遍历所有步骤，提取隐含前置条件 |
| GTP02 | 步骤可操作性 | 每一步是否可被精确执行？是否存在"整理归纳""分析评估"等需要具体操作定义的模糊动词？ | 警告 | 逐步骤检查动词精度 |
| GTP03 | 产出格式明确性 | 最终产出的格式/结构/长度/示例是否有定义？AI 是否有自主发挥的空间导致产出不可预期？ | 警告 | 检查输出规范定义 |
| GTP04 | 异常路径 | 任务中间出错是否有处理指令？用户输入不符合预期时行为如何？ | 警告 | 检查异常处理指令 |
| GTP05 | 结构锁定密度 | 锁定型提示词是否真的锁定了每一步（而非前端锁定后端自由）？原则型提示词的判断标准是否可操作？ | 警告 | 对比结构哲学声明与实际锁定程度 |
| GTP06 | AI味检测 | 同 GA07 | 警告 | 同 GA07 |
